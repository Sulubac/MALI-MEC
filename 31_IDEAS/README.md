## When To Use Ideas Folder

- You have a spark of inspiration but no plan yet
- You want to capture something without committing to it
- The idea needs more thought before becoming a project

## When To Promote An Idea

Move from `31_IDEAS/` to `02_PROJECTS/` when you decide to:
- Commit time to it
- Build a plan
- Start working on it

## Review Ideas Monthly

During monthly review, ask of each idea:
1. Is this still interesting?
2. Do I have time/resources to pursue it?
3. Should it become a project?
4. Has it been superseded?
5. Should I archive it?

## Naming Convention
