# 33 — NEEDS REVIEW

**Purpose:** Holding area for notes that could not be automatically classified.

**Rule:** Review every note here at least once per week. This folder should trend toward zero.

---

## How Notes End Up Here

A note is placed here when:
- Content is ambiguous (could be in 2+ folders)
- Missing dates, subjects, or context
- Mixed domains (personal + professional)
- Language unclear
- New domain not yet in the system

## How To Process A Note

1. Read the **full content** (not just the title)
2. Ask: what is the PRIMARY topic?
3. Apply the decision tree from [CLAUDE.md](../CLAUDE.md)
4. Move to the correct folder
5. Add full metadata
6. Log in [Needs Review Report](../SYSTEM/DELIVERABLES/03_NEEDS_REVIEW_REPORT.md)

## Escalation Rule

If a note has been here for **3+ weeks** without resolution:
- Option A: Create a new folder/category for it
- Option B: Merge its content into an existing note
- Option C: Archive it with `#NeedsReview` tag if no current value
