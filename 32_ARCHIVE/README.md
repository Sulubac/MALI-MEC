# 32 — ARCHIVE

**Purpose:** Completed, superseded, or inactive material. Read-only reference.

**Rule:** Nothing in Archive is ever deleted. Archive is permanent.

---

## Subfolders

| Folder | Contents |
|--------|----------|
| [2026/](./2026/) | 2026 archived notes |
| [2025/](./2025/) | 2025 archived notes |
| [2024/](./2024/) | 2024 archived notes |
| [2023/](./2023/) | 2023 archived notes |
| [Old_Projects/](./Old_Projects/) | Completed project folders |
| [Old_Notes/](./Old_Notes/) | Notes without specific year context |

## What Goes Here

- Completed projects (entire project folder)
- Superseded versions of documents
- Duplicate notes (prefixed `DUPLICATE_`)
- Meeting notes older than 2 years
- Inactive client records
- Old contracts (keep at least 10 years)
- Personal notes no longer needed

## What Does NOT Go Here

- Active project files
- Current contracts
- Reference material you actively use

## Adding To Archive

When archiving a note:
1. Move to appropriate year subfolder
2. Optionally add `ARCHIVE_` prefix to filename
3. Keep all original metadata
4. Update source folder's index if it had one
