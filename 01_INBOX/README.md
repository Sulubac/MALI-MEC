# 01 — INBOX

**Purpose:** Capture zone. Everything new lands here first.

**Rule:** Nothing lives here permanently. Process weekly.

**Target:** Inbox = 0 after every weekly review.

---

## How To Use

1. Dump any new note, link, idea, screenshot, or document here
2. Don't spend time organizing at capture time — just get it in
3. During weekly review: read each item, classify, and move to correct folder

## What Belongs Here

- Quick thoughts and ideas
- Links to save
- Screenshots and images
- Meeting notes captured on-the-fly
- Voice memos transcribed
- Emails forwarded for reference
- Articles to read later

## What Does NOT Belong Here

- Finished, classified notes (go directly to their folder)
- Old archived material (goes to `32_ARCHIVE/`)

## Processing Guide

For each item in Inbox, ask:
1. Is it actionable? → `02_PROJECTS/` or add to existing project
2. Is it reference material? → correct domain folder (07-14)
3. Is it about a meeting? → `18_MEETINGS/`
4. Is it an idea? → `31_IDEAS/`
5. Is it personal? → `05_PERSONAL/`
6. Still unsure? → `33_NEEDS_REVIEW/`
