## Client Folder Structure

```
04_CLIENTS/<CLIENT_NAME>/
├── README.md           ← client profile (from Client Template)
├── Meetings/           ← all meeting notes with this client
├── Contracts/          ← signed agreements
├── Invoices/           ← billing records
├── Emails/             ← important email threads
├── Reports/            ← deliverables sent to client
├── Presentations/      ← pitches and slide decks
└── Projects/           ← links to project folders
```

## New Client

1. Create folder: `04_CLIENTS/<CLIENT_NAME>/`
2. Fill README.md from [Client Template](../SYSTEM/TEMPLATES/CLIENT_TEMPLATE.md)
3. Add to [Client Map](../SYSTEM/MAPS/CLIENT_MAP.md)
4. Add to [Business Dashboard](../SYSTEM/DASHBOARDS/BUSINESS_DASHBOARD.md)
