## Standard Subfolder Structure

Every company folder contains:
```
<COMPANY>/
├── README.md           ← company profile
├── Projects/           ← active and past projects
├── Finance/            ← budgets, P&L, invoices
├── HR/                 ← staff records, contracts
├── Operations/         ← SOPs, workflows
└── Reports/            ← monthly/annual reports
```
