# MALI-MEC — Knowledge Management System

> **Mobile APP Loading Trucks** | Management & Engineering Consulting

## What Is This?

This repository is both an **active project workspace** (MALI-MEC Mobile App) and a **structured Second Brain** — a professional knowledge management system built on the PARA method, Johnny.Decimal numbering, and enterprise information architecture principles.

## Quick Start

1. **New note?** → Drop it in [`01_INBOX/`](./01_INBOX/) immediately
2. **Weekly review** → Process Inbox, move notes to correct folders
3. **Find anything** → See [`SYSTEM/MASTER_INDEX.md`](./SYSTEM/MASTER_INDEX.md)
4. **Check tasks** → See [`SYSTEM/DASHBOARDS/PROJECTS_DASHBOARD.md`](./SYSTEM/DASHBOARDS/PROJECTS_DASHBOARD.md)

## Naming Convention

All notes follow: `YYYY-MM-DD <Context> <Subject>`

Examples:
```
2026-07-25 OLA Meeting Fuel Loading Q3.md
2026-07-25 Techiftiin Budget Proposal 2027.md
2026-07-25 Claude API Prompt Engineering Notes.md
```
