## Naming Convention

```
YYYY-MM-DD <Company or Person> <Topic>.md
```

Examples:
```
2026-07-25 OLA Energy Q3 Operations Review.md
2026-07-25 Techiftiin Vision Session.md
2026-07-25 MEC Team Weekly.md
2026-07-25 MENFOP Grant Application Discussion.md
```

## Use The Template

Every meeting note must use: [Meeting Template](../SYSTEM/TEMPLATES/MEETING_TEMPLATE.md)

Required sections:
- Attendees
- Agenda
- Notes
- Decisions
- Action Items
- Next meeting

## After The Meeting

1. File note with correct naming
2. Extract action items → add to project or personal task list
3. Link from [Meetings Dashboard](../SYSTEM/DASHBOARDS/MEETINGS_DASHBOARD.md)
