# 19 — CONTRACTS

**Purpose:** Signed contracts — active and completed.

## Subfolders

| Folder | Contents |
|--------|----------|
| [Active/](./Active/) | Currently in force |
| [Completed/](./Completed/) | Fulfilled contracts |
| [_ARCHIVE/](./_ARCHIVE/) | Old contracts (keep 10+ years) |

## Naming Convention

```
YYYY-MM-DD CONTRACT-XXXX Client Description.md
```

## Required Fields

Every contract note should include:
- Parties
- Value
- Start and end date
- Key obligations
- Governing law
