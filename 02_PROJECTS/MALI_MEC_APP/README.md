# Project: MALI-MEC Mobile App

## Overview

**Project:** MALI-MEC Mobile App  
**Company:** MEC  
**Client:** OLA Energy  
**Purpose:** Mobile application for managing fuel truck loading operations  
**Status:** 🟡 In Progress — Requirements phase  
**Owner:** Ahmed Bache

---

## Description

MALI-MEC is a mobile application designed to digitize and streamline the fuel truck loading process for OLA Energy. The app replaces manual paper-based processes with real-time digital tracking.

## Objectives

1. Digitize fuel truck loading records
2. Provide real-time KPIs for operations management
3. Enable driver and vehicle tracking
4. Generate automated reports for OLA Energy

## Key Features (Planned)

- Loading record creation and management
- Driver management
- Fleet/truck tracking
- Depot management
- KPI dashboards
- Report generation
- Offline capability
