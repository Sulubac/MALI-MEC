# PROJECT TEMPLATE

> Copy this entire `_TEMPLATE/` folder to start a new project.
> Then fill in the README.md using the [Project Template](../../SYSTEM/TEMPLATES/PROJECT_TEMPLATE.md).

## How To Use

1. Copy `_TEMPLATE/` to `<PROJECT_NAME>/` in `02_PROJECTS/`
2. Rename to your project name (ALL_CAPS_WITH_UNDERSCORES)
3. Fill in `README.md` with project details
4. Create additional subfolders as needed
5. Add to [Project Map](../../SYSTEM/MAPS/PROJECT_MAP.md)
6. Add to [Projects Dashboard](../../SYSTEM/DASHBOARDS/PROJECTS_DASHBOARD.md)

## Standard Subfolders

All projects should have at minimum:
```
<PROJECT>/
├── README.md       ← project brief (required)
├── Meetings/       ← meeting notes (required)
├── Reports/        ← deliverables (required)
└── [Domain-specific subfolders as needed]
```
