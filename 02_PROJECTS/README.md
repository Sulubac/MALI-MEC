# 02 — PROJECTS

**Purpose:** Active multi-step initiatives with a defined goal and timeline.

**Rule:** A project must have a clear outcome. Ideas without commitment go to `31_IDEAS/`.

---

## What Is A Project?

A project is any work that requires **more than one action** to complete and has a **defined desired outcome**.

Examples:
- ✅ "Launch MALI-MEC Mobile App" — multi-step, clear outcome
- ✅ "Open Techiftiin Institute" — multi-step, clear outcome
- ❌ "Improve sales" — too vague, no clear outcome → `09_BUSINESS/`
- ❌ "Learn Python" — ongoing, no end date → `16_COURSES/`

## New Project Checklist

- [ ] Fill in `README.md` from [Project Template](../SYSTEM/TEMPLATES/PROJECT_TEMPLATE.md)
- [ ] Add to [Project Map](../SYSTEM/MAPS/PROJECT_MAP.md)
- [ ] Add to [Projects Dashboard](../SYSTEM/DASHBOARDS/PROJECTS_DASHBOARD.md)
- [ ] Add to [Master Index](../SYSTEM/MASTER_INDEX.md)

## Completing A Project

When a project ends:
1. Move entire folder to `32_ARCHIVE/`
2. Update Project Map status to "Completed"
3. Update Projects Dashboard
