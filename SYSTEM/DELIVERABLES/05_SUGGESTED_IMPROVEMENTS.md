---

## Known Limitations

1. **No real-time sync** — Git-based sync requires manual commit/push
2. **No binary file tracking** — PDFs, images, videos stored as links, not tracked in Git
3. **No concurrent editing** — Single user system currently
4. **Manual tagging** — Tags must be added manually until AI automation is set up
