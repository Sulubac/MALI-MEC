## Why Notes End Up Here

A note is placed in `33_NEEDS_REVIEW/` when:

1. **Ambiguous topic** — Could belong to multiple folders with equal probability
2. **Missing context** — No date, no subject, content too brief to classify
3. **Multiple domains** — Note covers 3+ unrelated domains
4. **Language unclear** — Mixed languages with unclear classification
5. **Personal + Professional** — Crosses personal/work boundary in unclear way
6. **New category** — Represents a domain not yet in the folder system

## Review Protocol

**Frequency:** Weekly (during weekly review session)

**Process:**
1. Open each file in `33_NEEDS_REVIEW/`
2. Read the full content
3. Apply the decision tree from `CLAUDE.md`
4. Move to the correct folder
5. Update this log
6. If still uncertain → add note explaining why and leave for next review

**Escalation:** If a note stays in Needs Review for 3+ weeks, consider:
- Creating a new folder/category for it
- Merging its content into an existing note
- Archiving it if it has no clear value
