# TAGS TAXONOMY

> Complete tag vocabulary for the MALI-MEC knowledge base.
> Use ONLY tags from this list. Add new tags here before using them.

---

## Usage

Add tags to the `tags:` array in note frontmatter:
```yaml
tags: [AI, Business, ActionRequired]
```

Use `#TagName` inline in note bodies for Obsidian-style linking.

## Tag Usage Rules

1. Use **3–8 tags** per note — more becomes noise
2. Always include at least one **domain tag** and one **status tag**
3. Add a **company/org tag** if the note belongs to a specific entity
4. Never create a new tag without adding it to this taxonomy first
5. Tags are **case-sensitive** — always use the casing shown above
